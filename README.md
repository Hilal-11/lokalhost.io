## ⚙️ Getting Started

<br />

**Prerequisites**

```
Node.js    18.17 or higher
Package    npm · yarn · pnpm · bun  (your choice)
```

<br />

**Clone & Install**

```bash
# Clone the repository
git clone https://github.com/your-org/lokallhost.git
cd lokallhost

# Install dependencies (pick your package manager)
npm install
# or
pnpm install
# or
yarn install
# or
bun install
```

<br />

**Start Development**

```bash
npm run dev
# → Open http://localhost:3000
```

<br />

**Build for Production**

```bash
npm run build    # Build optimized output
npm run start    # Start production server
npm run lint     # Run linter
npm run test     # Run test suite
```

```

├── 📁 templates/                  # Full-page, deploy-ready templates

├── 📁 mobile/
│   ├── react-native/              # RN components, screens & navigation
│   └── flutter/                   # Flutter widgets, screens & themes
│
├── 📁 design-kits/                # Figma tokens, assets & exports
├── 📁 lib/                        # Utilities, hooks, helpers, configs
├── 📁 styles/                     # Global styles & design tokens
└── 📁 public/                     # Static assets & media
```
